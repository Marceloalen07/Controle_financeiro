# 💰 Controle Financeiro Pessoal

Aplicação desktop desenvolvida em Python para auxiliar no controle de receitas e despesas pessoais, permitindo registrar movimentações financeiras e acompanhar o saldo de forma simples e intuitiva.

## 📌 Sobre o projeto

O Controle Financeiro Pessoal foi desenvolvido com o objetivo de praticar conceitos de programação em Python, criação de interfaces gráficas e armazenamento de dados em arquivos JSON.

## ✨ Funcionalidades

- Cadastro de receitas e despesas.
- Organização das movimentações por categoria.
- Visualização do histórico financeiro.
- Cálculo automático do total de receitas, despesas e saldo.
- Exclusão de movimentações.
- Armazenamento local dos dados em arquivo JSON.

## 🛠️ Tecnologias utilizadas

- **Python:** linguagem de programação utilizada no desenvolvimento.
- **Tkinter:** criação da interface gráfica.
- **JSON:** armazenamento local das movimentações financeiras.
